How it works

Data

Ten years of daily prices for each market come from Yahoo Finance every evening through a GitHub Actions job. Prices are adjusted for splits and dividends, so a 2-for-1 split doesn't look like a 50% crash. UK shares are quoted in pence.

Forecast cone

4,000 simulated futures, each built by resampling 5-day blocks of the last 500 daily returns. The average return is removed first, so the cone measures how far the price could move, not which way. The bands show where 50% and 90% of the simulated paths ended up.

Backtest

Walk-forward with no lookahead: on each day, each model only sees data up to that day's close. The learned models retrain every 21 trading days on the previous 750 days. A strategy holds the asset when its model predicts a rise and holds cash otherwise, paying 0.05% each time it switches.

Testing the result

Accuracy alone is misleading, because markets rise on more than half of days. Each model is compared with "always up" using McNemar's test on the days where the two disagree. A p-value under 0.05 is shown as significant, but with 5 models on 30 markets, about 4 would look significantly better by luck alone.

This site is a statistics project, not financial advice. Past performance does not predict future returns.
